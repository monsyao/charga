# Очередь — группа 2

Минимальное приложение для очереди на лабораторные работы.

## Что уже настроено

- Статический сайт для GitHub Pages.
- Пять циклов в течение дня:
  - 08:00–09:25, запись с 07:50;
  - 09:35–11:00, запись с 09:25;
  - 11:25–12:50, запись с 11:15;
  - 13:00–14:25, запись с 12:50;
  - 14:40–16:05, запись с 14:30.
- Очередь без ограничения по длительности: студент сам нажимает «Сдал лабу».
- При переходе к следующему циклу очередь начинается заново, история старого цикла не удаляется.
- Если студент нажимает «Сдал лабу», более ранние незавершённые записи помечаются как пропущенные.
- Есть демо-режим через localStorage, чтобы проверить интерфейс без Firebase.

## Подключение Firebase

1. Создай проект на https://console.firebase.google.com.
2. Включи **Realtime Database**.
3. Включи **Authentication → Sign-in method → Anonymous**.
4. Создай Web App и скопируй его конфигурацию.
5. Вставь значения в `firebase-config.js`.
6. В Firebase Realtime Database открой Rules и вставь содержимое `database.rules.json`.
7. Загрузи все файлы в GitHub-репозиторий и включи GitHub Pages.

Не публикуй пароль Google-аккаунта или service-account key. Web-конфигурация Firebase сама по себе не является паролем, но правила базы должны быть настроены.

## Публикация на GitHub Pages

1. Создай новый репозиторий.
2. Загрузи `index.html`, `styles.css`, `app.js`, `firebase-config.js`, `database.rules.json` и `README.md`.
3. Открой **Settings → Pages**.
4. Выбери публикацию из ветки `main`, папка `/root`.
5. Открой выданный адрес сайта.

Для локальной проверки можно открыть `index.html` напрямую: в этом случае будет работать демо-режим.
